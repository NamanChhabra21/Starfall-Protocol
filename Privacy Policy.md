# Privacy Policy

Last Updated: 01 June 2026

This game is personal project created using Python. 

### Information Collection

The game may store simple local data such as:

- High score
- Game settings
- Progress data
- User Feedback and Rating
- Total play time
- Last played time
- Name ( optional ) 

This information is stored on the user's device and Firebase for analysis. 

### No Personal Data Collection


This project does not collect:

- Passwords
- Email addresses
- Personal identity information

### No Online Tracking

The game does not use:

- Online tracking
- Advertisements
- Remote servers

### Third-Party Libraries

This project may use open-source Python libraries such as:

- Pygame
- PyInstaller
- Other multimedia libraries

These libraries are used only for game functionality.


This project was created for educational and learning purposes.

### Changes

This privacy policy may be updated in future versions of the project.
